# Compare approaches

Use when the user asks to compare approaches or choose among them. Do not reopen a choice the user already made when they only ask for execution.

1. Identify the requested result and constraints. Inspect available evidence before asking for facts already present.
2. Find a small set of credible alternatives. Separate documented capability from vendor claims and untested assumptions.
3. Compare against the user's actual constraints, not a generic feature count. Recommend one approach and explain which changed condition would alter the choice.
4. Cite evidence and identify remaining uncertainty. A recommendation does not authorize implementation, installation, or publication.

If the required evidence is unavailable, state the limitation and provide the supported portion. Do not fabricate a comparison or continue searching indefinitely without a specific unresolved question.
